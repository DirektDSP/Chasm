
# Chasm

**Chasm** is a diffusion / delay plugin developed by DirektDSP in collaboration with Korzana.
Inspired by Korzana's personal FX chains, Chasm combines 7 different effect plugins into one, making your production easier and faster (and lighter on your CPU).

## Features

- **Custom Diffusion Effect**: Signature smeary/blurred sound.
- **Stereo Control**: Haas effect and Width control to make your sounds big.
- **Brightness & Character EQ**: Shape the tone of the diffusion with Character and account for high end loss with brightness.
- **Built-in MakeItLoud Compression/Distortion**: Add punch and harmonics with integrated compression/distortion. Also available as a standalone plugin!
- **Smooth Parameter Automation**: No artifacts when tweaking or automating parameters.
- **Comprehensive Preset System**: Built in artist credits and almost 100 stock presets to start with. Organize them into categories to make finding them easier too!

## Perfect For

- Vocal processing
- Pads and textures
- Smoothing out transients
- Wide & immersive soundscapes
- Synth and Bass sound design

> Try chain multiple together to see what happens!

## Technical Specs

- VST3, AU, AAX formats
- 64-bit only
- Low CPU usage (optimized for real-time use)
- Full automation support
